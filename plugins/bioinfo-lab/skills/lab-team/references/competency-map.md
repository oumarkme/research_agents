# Competency map

Built from the ISCB bioinformatics core competencies (Mulder et al., 2018, https://doi.org/10.1371/journal.pcbi.1005772; areas A to P and ten user personas), plus domain standards for breeding, genomic prediction, association studies, sequencing, clinical genetics, data stewardship, and publishing. Checked 2026-10-22. A search did not return a validated competency framework for new academic PIs, so planning and mentoring skills rest on practice, not on a cited standard.

| Ability (ISCB area or domain) | Skill | Main agent |
|---|---|---|
| Biological data generation technologies (C) | `sample-and-assay-planning` | `data-steward`, `bioinformatician` |
| Tools and their usage (F) | `sequencing-pipelines` | `bioinformatician` |
| Orientation for any user level | `start-here` | main session |
| Command line, scripting, software construction (J, K) | `coding-style` | `software-engineer`, `bioinformatician` |
| Statistical research methods (E) | `study-design` | `statistician` |
| Quantitative genetics, animal and plant breeding | `quantitative-genetics` | `breeder` |
| Genomic prediction and polygenic scores | `genomic-prediction` | `statistician`, `breeder` |
| GWAS, QTL, Mendelian randomization | `association-studies` | `statistician` |
| Genomic data pitfalls | `genomics-pitfalls` | all analysis agents |
| Clinical genetics and variant interpretation | `variant-interpretation` | `clinical-geneticist` |
| Scientific discovery process, evidence (D) | `trusted-sources`, `study-design` | all |
| Professional, ethical, legal, security issues (M) | `research-ethics` | `data-steward` |
| Data management, FAIR, reproducibility | `data-stewardship` | `data-steward` |
| Effective communication (N) | `project-readme`, `writing`, `translator`, `plotting`, `stakeholder-communication` | `writer`, `translator` |
| Teamwork and collaboration with breeders and physicians (O) | `stakeholder-communication` | `writer`, `breeder`, `clinical-geneticist` |
| Project planning, grants, mentoring (P, practice-based) | `research-planning` | main session, `writer` |
| Delegation and cost control | `lab-team`, `lab-rules` | main session |

Standards used (all verified in Crossref): ACMG/AMP (Richards 2015), ACMG/ClinGen CNV (Riggs 2020), AMP/CAP pipeline validation (Roy 2018), GIAB benchmarking (Zook 2019; Krusche 2019), PRS-RS (Wand 2021), STROBE-MR (Skrivankova 2021), FAIR (Wilkinson 2016), reproducibility (Sandve 2013; Wilson 2017), genomic selection (Meuwissen 2001; VanRaden 2008; Crossa 2017), GWAS (Uffelmann 2021). Policy items taken from secondary sources and flagged for checking against official pages: ICMJE and Springer Nature AI policies, Taiwan biobank and data-protection law.
