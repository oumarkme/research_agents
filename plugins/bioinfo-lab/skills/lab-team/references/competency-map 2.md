# Competency map

Built from the ISCB bioinformatics core competencies (Mulder et al., 2018, https://doi.org/10.1371/journal.pcbi.1005772; areas A to P and ten user personas), plus domain standards for breeding, genomic prediction, association studies, sequencing, clinical genetics, microbial and evolutionary genomics, data stewardship, and publishing. The framework is not tied to one organism group. Checked 2026-10-22; rows for the 35 task skills added 2026-11-06 and for the 24 skills of version 2.0.0 added 2026-11-07. ISCB letters appear only where the framework names the area; "domain" and "practice-based" mark areas without a letter. No validated competency framework for research planning was found, so `research-planning` rests on practice, not on a cited standard.
