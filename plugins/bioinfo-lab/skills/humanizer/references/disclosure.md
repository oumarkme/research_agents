# Disclosure

Editing prose and declaring artificial intelligence (AI) use are separate duties. This skill does the first and prompts for the second. Rules checked 2026-11-05 from the primary pages marked "read". Pages differ in date and wording, so re-read the target journal's live page before each submission.

## Default

Declare any pass in which a model rewrote sentences, not only fixed spelling or grammar. That is a cautious reading: the exemptions below cover grammar, spelling, and general editing, and none of the pages read states that sentence-level rewriting is exempt.

## Rules by body

| Body | Rule in brief | Status |
|---|---|---|
| ICMJE | No AI authors. Disclose at submission, in the cover letter and the work. Nondisclosure "may be construed as misconduct in some circumstances". | read |
| COPE | Disclose in Materials and Methods: tool and how it was used. | read |
| Elsevier (updated July 2026) | Basic grammar, spelling, and punctuation checks need no declaration. Otherwise add a statement above the references. | read |
| Wiley | Tools used "solely for spelling, grammar, and general editing" are exempt. | read |
| PLOS | No disclosure required for language improvements. | read |
| Springer Nature | Copy-editing need not be declared, but another line on the same page says use "should be declared". Treat the exemption as uncertain. | read, internally inconsistent |
| Bioinformatics (OUP/ISCB) | Spelling and grammar aids and translation allowed, with disclosure in the cover letter and Methods or Acknowledgements. Drafting a paper from a prompt is "not acceptable". | read |
| Frontiers | Acknowledge AI-edited content with tool name and version. | read |
| NIH, NOT-OD-25-132 | Applications "substantially developed by AI" will not be considered. NIH states it uses AI-detection technology. | read |
| NTU generative AI guideline (June 2026) | Disclose tool, version, date, purpose, operation, and degree of involvement. Keep a log of key prompts, outputs, and human revisions. Heavy, influential, undisclosed use can count as plagiarism. | read (PDF) |
| Nature Portfolio, Science, MDPI, Cell Press, BMJ, JAMA, NAR, ACMG journals | Not read first-hand (cookie gate, HTTP 403, or page not found). | check before submission |
| NSTC, NTUH | No research-writing guideline found. | confirm with the research integrity office |

## Declaration template

Composed from the elements journals ask for; it is not quoted from any journal. Adapt it to the journal's placement rule (Methods, Acknowledgements, or a dedicated statement).

> During the preparation of this work, the author(s) used [tool and version] on [date] to [purpose, for example "edit the wording of the Introduction"]. The author(s) reviewed and edited the output and take full responsibility for the content.

Keep a log of the prompts, outputs, and revisions (`analysis-log`). National Taiwan University (NTU) asks for it, and it answers any later query.

## Reviewing

Do not upload a manuscript or grant under review to a public AI tool. The National Institutes of Health (NIH) bar AI use by reviewers (notice NOT-OD-23-149), and the publishers surveyed bar uploading confidential manuscripts.
