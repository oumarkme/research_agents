# Crops, livestock, model organisms, and microbes

Checked 2026-10-22. Sites marked "blocks scripts" returned 403 to the link check but exist; use a browser.

## Plants and crops

| Resource | Use | Query | Access |
|---|---|---|---|
| Ensembl Plants | Plant genomes, variation, comparative genomics | `plants.ensembl.org`; REST `rest.ensembl.org` with the plant species name | open |
| Gramene | Plant genomes, pathways, diversity | `gramene.org`; API `https://data.gramene.org/` | open |
| Phytozome | Plant genome portal | `phytozome-next.jgi.doe.gov` | key for downloads |
| TAIR, Araport | Arabidopsis | `arabidopsis.org` (blocks scripts), `araport.org` | open; TAIR may need a login |
| MaizeGDB, SoyBase, GrainGenes, Sol Genomics, CottonGen, GDR | Crop community databases (maize, soybean, small grains, Solanaceae, cotton, Rosaceae) | `maizegdb.org` (blocks scripts), `soybase.org`, `wheat.pw.usda.gov/GG3/`, `solgenomics.net`, `cottongen.org`, `rosaceae.org` | open |
| Planteome and Crop Ontology | Trait, plant structure, and variable ontologies | `planteome.org`; `cropontology.org` | open |
| BrAPI and MIAPPE | Breeding data exchange and phenotyping metadata standards | `brapi.org`; `miappe.org` | open |
| Genesys | Germplasm accession passport data | `genesys-pgr.org` | open |
