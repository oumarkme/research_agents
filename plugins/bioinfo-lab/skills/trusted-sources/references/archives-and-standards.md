# Archives, standards, and tools

Checked 2026-10-22.

## Sequence and data archives

| Resource | Use | Query | Access |
|---|---|---|---|
| ENA, NCBI SRA, DDBJ | Raw reads and assemblies (mirrored, INSDC) | ENA Portal API `https://www.ebi.ac.uk/ena/portal/api/`; `ncbi.nlm.nih.gov/sra`; `ddbj.nig.ac.jp` | open |
| dbGaP, EGA | Controlled-access human genotype and phenotype data | `ncbi.nlm.nih.gov/gap/`; `ega-archive.org` | controlled |
| Zenodo, Dryad | Code, small data, supplementary files with DOIs | `zenodo.org`; `datadryad.org` | open |
| re3data, FAIRsharing | Find a repository or a standard | `re3data.org`; `fairsharing.org` | open |

## No-install analysis options

For users without servers, containers, or command-line tools: the UCSC Genome Browser and Table Browser (`genome.ucsc.edu`), Ensembl BioMart and VEP web tools (`ensembl.org`), NCBI web tools, and Galaxy (`usegalaxy.org`, runs workflows in a browser). Record the tool version or release shown on the page.
