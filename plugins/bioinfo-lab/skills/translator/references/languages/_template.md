# Language file template

Copy to `<code>.md` (for example `ja.md`) and fill in, or use the questions below once per session when no file exists. Keep it under 40 lines.

* **Script and variant**: which script, which regional standard (for example Brazilian or European Portuguese), and which spelling reform.
* **Technical terms**: keep English, or use the local term? Name the source that settles it (a national terminology database or recent journals in that language). Verify, do not guess.
* **Punctuation and spacing**: quotation marks, decimal separator, thousands separator, spacing around Latin text and units. Numbers in the target must still match the source value for value.
* **Register**: the academic register of the target language (for example the formal plural of authors in Spanish and French, or the polite level in Japanese and Korean).
* **Strength-of-claim verbs**: the target words for *show*, *suggest*, *may*, *associated with*. Never upgrade association to causation.
* **Restructuring**: where the target language needs different sentence order, explicit subjects, or shorter sentences.
* **Checks that do not apply**: the `writing` lint script covers English and Chinese only. Say so in the report for any other language.
