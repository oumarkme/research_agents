# Log entry

Paste into `PROGRESS.md` of the project `analysis-log`.

```
## Lookup: <short question>
- Date retrieved: YYYY-MM-DD
- Constraints: <organism, data type, scale, platform>
- Sources: <URL or DOI> (verified | snippet | blocked); <second source>
- Choice: <tool or method, exact version>
- Why: <one to two sentences, with the evidence>
- Conflicts: <what disagreed, and design differences>
- Not verified: <items>
- Recheck by: YYYY-MM-DD, or on <event: new major release, new guideline>
```

Expiry hint: set the recheck date from the field speed you judged (months for fast, a year or more for slow).
