# Search recipes

Generic patterns. Replace the angle-bracket parts. Add the date you searched to the log.

## Web

* `<task> benchmark <year>` and `<task> comparison independent evaluation`
* `<tool> release notes` and `<tool> changelog`
* `site:github.com <tool> releases` (check the date of the latest release and the last commit)
* `<tool> deprecated OR unmaintained OR "superseded by"`
* `<database> release notes <year>`
* `<guideline> update <year>` for a society guideline

## PubMed

* `<task>[Title/Abstract] AND (benchmark*[Title/Abstract] OR compar*[Title/Abstract])`
* Filters: Review, Systematic Review, last 2 or 5 years; sort by date.
* Run a second, differently worded query before you report that nothing exists.
* Check a hit: `<first author> <year> <journal>`, then the DOI on Crossref.

## Europe PMC

* Includes preprints: filter by source `PPR` to list them, and label them `preprint`.
* `CITES:<PMID>_MED` lists papers citing a benchmark; use it to find newer ones.

## Preprints

* bioRxiv and medRxiv: browse by subject category and date range; newest first.
* Check whether the preprint was later published (the server links the journal version).

## Corrections

* Search the DOI with `retraction OR correction OR erratum`; read the Crossref update notice.
